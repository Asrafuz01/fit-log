# 💪 FitLog

FitLog is a modern workout library and workout planning application built with Next.js.

Users can browse workouts, view detailed exercise instructions, create a daily workout plan, save workouts for later, and track completed exercises.

## 📦 Technologies

- Next.js
- React
- App Router
- Tailwind CSS
- daisyUI
- JavaScript
- REST API
- LocalStorage

## ✨ Features

1. Browse workout library from API data
2. Responsive workout cards
3. Dynamic workout details pages
4. Add workouts to Today's Plan
5. Save workouts for later
6. Live plan and saved counters
7. Mark workouts as done
8. Remove workouts
9. Sort workouts by duration, calories, or rating
10. LocalStorage persistence
11. Responsive design for mobile, tablet and desktop
12. Custom 404 page
