
# 💪 FitLog — Workout Library & Planner

**Train with intent. Log every set.**

FitLog is a modern and responsive workout library and workout planning application built with Next.js. It helps users discover exercises, explore detailed workout instructions, organize daily workout plans, save workouts for later, and track completed exercises.

## 🌐 Live Project

- **Live Website:** https://fit-log-lac.vercel.app/
- **GitHub Repository:** https://github.com/Asrafuz01/fit-log

## ✨ Key Features

- **Workout Library:** Browse a collection of workouts using data from a REST API.
- **Workout Details:** Explore individual workouts through dynamic detail pages.
- **Today's Plan:** Add workouts to a personalized daily workout plan.
- **Save for Later:** Save exercises for future workouts.
- **Workout Tracking:** Mark planned workouts as completed.
- **Plan Management:** Remove workouts from your daily plan.
- **Live Counters:** View updated plan and saved workout counts.
- **Sorting:** Sort workouts by duration, calories, or rating.
- **Persistent Data:** Keep workout plans and saved items using LocalStorage.
- **Responsive Design:** Designed for mobile, tablet, and desktop screens.
- **Custom 404 Page:** Display a dedicated page for unavailable routes.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Asrafuz01/fit-log.git
```

### 2. Navigate to the Project Directory

```bash
cd fit-log
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

`http://localhost:3000`
